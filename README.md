# 🌿 MindLink frontend coursework

A smaller frontend coursework repository with six HTML screens, CSS and a specialist-matching script. No backend or deployment configuration is included.

## 🚀 Explore locally

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/index.html`. This previews the static screens. Authentication, saved assessments, appointments and JSP rendering require a backend and are not functional in the static preview.
